# 合成テスト用ジョブ（PAT_*.JBI）の一覧と期待結果

**ここにあるジョブは合成（架空）のデータで、実機由来のデータではありません。実機のジョブはリポジトリに入れません。**

- すべて `DEMO_PLACE.JBI` をもとに、このリポジトリで新しく作った架空の値です。各ファイルの INST 部に「合成テスト用（実機のジョブではない）」のコメント行があります（ASCII のファイルでは `'SYNTHETIC TEST DATA - NOT A REAL ROBOT JOB`）。
- 実機検証の前に、読み込み・変更・止める判定を確かめるために使います。ロボットで動かすためのジョブではありません。
- ファイルは `tools/make_dummy_patterns.py` でバイト列として書いています（Shift_JIS もエディタで保存していません）。何度実行しても同じバイト列になります。直すときはスクリプトを直して作り直してください（`python tools/make_dummy_patterns.py`。確かめるだけなら `--check`）。
- テストは `tests/test_dummy_patterns.py`。
- 検査を通ることは、物理的な安全の保証ではありません。

## 期待結果の書き方
- **変更できる**：`plan_shift`（位置の Z を +5mm）または `plan_speed`（速度を 100.0 に）が変更案を返す。変わるのは1行だけ
- **止まる**：変更せず、理由を返す
- 根拠：仕様v2.1 6章「止める条件」・7章、CURRENT_DECISIONS 4章、docs/JBI_FORMAT_NOTES.md
- **xfail**：今の `voice_teaching/jbi.py` が正本と違うため、テストを `xfail(strict=True)` にしているもの（jbi.py の修正待ち。直ったら xfail を外す）

## C変数だけのデモ JOB（DEMO_C_PLACE.JBI）
実機では P変数の使用枠が上限に達しているため、デモは C変数（ジョブの中の位置）方式で行う（唐川さん、2026-11-02）。
このジョブは **P変数を一切使わない**。合成（架空）の値で、実機のジョブではない。改行は CRLF、文字コードは ASCII。

| 位置 | 意味（合成） | 入る／出る移動 |
|---|---|---|
| C00000 | 開始の点 | 最初の移動（直前の移動命令が無いので、実機用の検査では変更を止める） |
| C00001・C00002・C00003 | 取る点の真上・取る点・真上へ戻る点 | MOVL（PL=0） |
| C00004・**C00005**・C00006 | 置く点の真上・**置く点（デモの対象）**・真上へ戻る点 | MOVL（PL=0）。置く点の直後に TIMER 3秒 |
| C00007 | 終わりの点 | 最後の移動（次の移動命令が無いので、実機用の検査では変更を止める） |

試し方：画面で読み込み → C00005 を選ぶ →「この位置を上に10mm」→ 確認表示 → 承認 → シミュレーション用の出力（`output/sim/DEMO_C_PLACE_SIM.JBI.txt`）。
差は `//NAME` と C00005 の行の2行だけ（tests/test_demo_c_job.py）。最新の安全ガード（fix/safety-guards）でも C00005 の変更は通る（2026-11-02 に確認）。
