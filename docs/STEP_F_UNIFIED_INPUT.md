# Step F：発話の入口を1つにする（2026-11-04 未明・家のPC・シクロ。試し：`wip/scene3-connect`）

唐川さんの指示（11/3 夜）：「このロボット、何してる？」「ここを3ミリ下げて」「じゃあ3回にして」を、同じマイク・同じ入力欄から。
自然な言い方は Claude に理解させてもよいが、座標・移動量・回数などの大事な情報は、決定論のプログラムで確かめる。
CHECKER_031 3章の1〜8（読み取りから変更エンジンへつなぐときの注意）を守る。

## 1. 入口：`POST /api/talk`（`WebFlow.talk`）
会話の欄（「Claude に聞く」）の送信は、すべてここへ。答えは `{via, ask, hear, state}`。

## 2. 振り分け（まずプログラムが決める。`WebFlow._talk_route`）
| 順 | 条件 | 行き先 | Claude |
|---|---|---|---|
| 1 | 承認前で、会話（位置の候補）の途中・回数の範囲の確認の途中 | 指示の道（hear） | 呼ばない |
| 2 | 承認・出力・転送・保存・起動・確定・エクスポート などの言葉 | 決まった文だけ（状態を変えない。承認も取り消さない） | 呼ばない |
| 3 | 承認のあとで、変更の無い言葉（「はい」「OK」） | 決まった文だけ（承認は取り消さない） | 呼ばない |
| 3' | 承認のあとで、変更の無い質問（「何をしている？」「教えて」） | 会話の道（説明だけ。承認は取り消さない） | 呼ぶ（読み取りだけ） |
| 4 | 「どの動きのことですか？」の途中 | 会話の道（ask。ボタンで確かめる） | 呼ばない |
| 5 | 利用者の文から、プログラムが回数を読めた（「じゃあ、3回にして」「もう1回増やして」） | 会話の道（Claude が答える）＋変更の道へ**プログラムの決まった文**（下の3） | 呼ぶ（読み取りだけ） |
| 6 | プログラムが指示として読める（位置・速度・選択・元に戻す・比べる・軸・量・位置番号・場所の言葉・〜ます） | 指示の道（hear） | 呼ばない（今の解釈の係） |
| 7 | それ以外（説明・意味を教える） | 会話の道（ask） | 呼ぶ（読み取りだけ） |

## 3. 回数の変更の希望 → 範囲の確認のボタン
- 変更の道へ渡すのは、`rc.canonical(区間の最初の位置, 区間の最後の位置, 今の回数, 利用者の文の回数)` の決まった文だけ
  （例：「C00001からC00003の作業を2回から3回にして」）。区間・今の回数はプログラムが数え、回数は利用者の文から読む。**Claude の数は使わない**
- 区間はプログラムが決める：`talk.read_count` が決めた区間 → 無ければジョブの区間が1つのときその区間 → 決まらなければ利用者の文のまま（変更の道が範囲を聞き返す）
- そのあとは今までどおり：範囲の確認のボタン［この範囲を繰り返す］（人が押す）→ `confirm_repeat` → 候補 → 3D の比較 → 確認表示 → 名前＋［承認する］
- 打ち消し・ためらい（「3回にしないで」）、承認待ちの候補があるとき、Claude の答えの回数が合わないとき：範囲の確認を始めない（会話の道は決まった文）
  ※ Claude の答えの数が合わなくても、範囲の確認は**プログラムが読んだ数**で始める（Claude の文は出さず、食い違いの決まった文）
- 範囲の確認を始めたら、会話の欄の「読み取りだけです」「候補は作りません」の文は、今の状態と合う文（「範囲を確かめてください…」）にする

## 4. Claude の答えの検査（会話の道。`claude_explain`・`claude_talk`）
- 数は「事実と合う言い方」だけ（許可リスト）。許した言い方は1回だけ取り除き、まだ数が残れば検証エラー（文は書き換えない）
  - 変更の確認：「今の回数から変える回数」「変える回数に」「今の回数のまま」「今の回数くり返」、この文の「N回増やして」
  - 説明：プログラムが数えた回数（回・度）、区間の位置の数（か所）、ジョブにある行番号
  - 移動量（数＋mm・ミリ・cm・メートル など）は出さない。ジョブに無い位置番号は出さない。数字を使わない回数（三たび・さんかい）も出さない
- 人が教えていない目的の言葉（ボタン・押す など）は「AI の推定」の印

## 5. 守っていること
- 候補を作る入口は今までどおり Session の `_accept`（位置）と `confirm_repeat`（回数）だけ。`/api/talk` は候補・承認・出力を直接作らない
- 承認は確認表示のボタンだけ。出力は出力のボタンだけ。声・文字では行わない。実機への出力・転送・起動は無い
- マイクは1回の発話で OFF（自動で聞き直さない）
