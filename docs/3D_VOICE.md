# 3D と声で動かす（feat/3d-voice）

唐川さんの最終指示（2026-11-02 夜）：「JOBを読み込む。3Dでポイントを見る。声で動かす。確認する。」

- ブランチ：`feat/3d-voice`（`feat/ui-4steps` の 86c1a89 から。安全修正 f7eddc7 を含む）
- feat/mvp・feat/ui-4steps へはマージしていない（クロちゃんのレビューと唐川さんの承認の後）
- 実機用の JOB の生成・転送・起動は無い。シミュレーション専用のまま

## 朝の使い方（唐川さん向け）

```
cd C:\Users\User\voice-teaching
git switch feat/3d-voice
.venv\Scripts\python -m voice_teaching.web       # http://127.0.0.1:8765/ を Chrome で開く
```

1. `samples/dummy/DEMO_C_PLACE.JBI` を画面にドロップ → 3D に点と経路が出る
2. 3D をドラッグで回す・ホイールで拡大縮小・「視点を戻す」。点 C00005 を押す
   （重なって見える点 C00000／C00007 などは、押すと選び分けの一覧が出る）
3. マイクの方式を選び（まず「ブラウザー標準」）、🎤 を押して「この位置を上に2ミリ」と話す →「話し終わった」
4. 入力欄の文を確かめて（直してもよい）「次へ」→ 変更前（灰）と変更後（オレンジ）が 3D で再生され、右上に「変更の向き（拡大）Z +2.000mm」
5. 「確認して承認へ」→ 全画面の確認表示（注意・図・差分・変わる命令の行）→ 名前を入れて「承認する」→「シミュレーション用に出力」

マイクは一度 ON にすると、結果が出たあと続けて聞き始める（Web会議のように）。止めるときは「マイクをOFF」か、一時停止中の 🎤。

## 本物の Claude で試すとき（唐川さんが用意）

- Anthropic Console で API キーを作り、クレジットを入れる（Claude Code のログインでは使えない）
- リポジトリ直下に `.env` を作る（`.gitignore` 済み。コミットしない）：`ANTHROPIC_API_KEY=...`（任意で `ANTHROPIC_MODEL=`。既定は claude-opus-5-5）
- サーバーを起動し直す。上の帯の印が「解釈：モック」→「解釈：Claude」に変わる
- Claude に送るのは、指示の文・選んでいる位置番号・位置番号の一覧だけ（ジョブの中身・座標は送らない）
- 失敗したとき（キー違い・通信・拒否）はモックに切り替えず、固定の文で止める（キーや生のエラーは画面に出さない）

## 方向と座標系（決まりを広げていない）

- 「上」「下」＝ Z+／Z−：FRAME v1.1 6章の「枠が無いときは今どおり Z±」のまま（変えていない）
- 「右」「左」：軸が決まっていないので聞き返す（FRAME v1.1：実機確認（11/3夜）まで未定）
- 「Xプラス」「Y-」など、軸と向きを言った指示はそのまま使う
- FRAME（専門家の枠）は実装していない。FRAME v1.1 の「着手は安全ガードの統合が feat/mvp に入ったあと」が満たされていないため。
  したがって C00005 の ±15mm・Y だけ、という枠の制限もまだ無い（今の 20mm の上限・ガードはそのまま。広げていない）
- 2つ以上の変更をまとめて1つの候補にすることはしない（ガード・承認・出力が1つの変更を前提にしているため）

## 音声認識：調べたこと（2026-11-02 夜。この PC：Windows 11・Chrome 156）

| 確かめたこと | 結果 | 確認の方法 |
|---|---|---|
| Chrome の音声認識が使えるか | `SpeechRecognition` あり。`processLocally`・`available()`・`install()` あり | 実際の Chrome 156 を Playwright で起動 |
| 「ブラウザー標準」（Google のサーバーで認識） | 音声のトラックを直接渡した試しで、認識結果（「中」）が返った。**今夜は network エラーは出なかった** | Windows の音声合成（Haruka）で作った「この位置を上に2ミリ」を偽のマイクに流した |
| 偽のマイクから既定の方法（`start()`） | no-speech（音が届かない）。getUserMedia には音が届いている（ピーク 1.0）。Web Speech は偽のマイクの音を使わないらしい | 同上。実マイクでの確認は唐川さん |
| 「端末内のみ」の日本語 | 最初は `downloadable`（入っていない）→ アプリでは「日本語の言語パック…」のエラー。`install()` で **12.6秒で入り `available` になった**（一時プロファイル） | 同上 |
| 端末内のみの認識結果 | 偽のマイクでは no-speech／トラック渡しでは language-not-supported。**実マイクでの確認は未** | 同上 |

network エラーの原因の候補（未確認。前回のエラーの時の状況が分からないため断定しない）：
- 「ブラウザー標準」は音声を Google のサーバーへ送って認識する。インターネット・プロキシ・VPN・社内のフィルター・一時的な障害で network になる
- Chrome 以外（Chromium 系の別ブラウザー、Playwright 同梱の Chromium）では、Google のサーバーを使えず network になることがある
- 対策としてアプリでしたこと：失敗したらマイクを OFF にして文字の入力へ案内。端末内のみ（日本語の音声データを入れれば通信不要）を選べるように
