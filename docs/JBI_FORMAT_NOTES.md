# JBIの書き方：前提と確認待ちの点

`samples/dummy/` のジョブは、このリポジトリで新しく作った**架空のジョブ**です（実機のジョブではありません）。
安川のJBIの一般的な書き方をもとにしています。次の点は、実機で作ったサンプルで確認してから確定します。

| 前提 | 状態 |

## このアプリの方針
- 分からない行は、**一文字も変えずにそのまま残す**
- 変えるのは、検査を通った位置の数値1つ、または速度の数値1つだけ
- 変更はまず変更案（`ChangeProposal`）として作り、元のジョブは変えない。変更後の値は、新しいジョブを読み直した実際の値を出す

### ジョブ全体を止める（変更をすべて断る）もの
次のどれかがあれば、ジョブを「読めない所がある」として、位置も速度も変えない。
- POS部の読めない行（`BC`・`EC` などの行を含む）
- 位置の値に数値でないものがある（`nan`・`inf`・`1_000` なども数値とみなさない）
- 位置の値が3個未満
- 同じ名前の位置が重複している
- INST部の `///GROUP1 RB1` 以外の GROUP 行（複数の軸グループ）
- （原本より厳しい追加）`//NAME`・`//POS`・`//INST` 以外の見出し（`//ALIAS` など）や、同じ見出しの重複
- （原本より厳しい追加）INST部の `///DATE`・`///ATTR`・`///COMM`・`///GROUP1 RB1` 以外の指示行（`///LVARS` なども止める）
- （原本より厳しい追加）`///NPOS` が無い、読めない、または位置の行の数と合わない
- （原本より厳しい追加）行の中のタブ以外の制御文字や、`\n` を伴わない `\r`

### 位置の変更（`plan_shift`）を断るもの
- 上の「ジョブ全体を止める」ものがある
- 移動量が bool、0、有限でない（nan・inf）、数値でない
- 移動量が上限を超える（`DEFAULT_MAX_SHIFT_MM = 50.0`。唐川さんの確認待ちの仮の値）。丸めた後の実際の移動量も上限を超えないか確かめる
- 位置が無い、軸が X・Y・Z 以外
- 位置がロボット座標でない（位置ごとに判定する）。知らない指示行より後ろの位置も変えない
- ジョブに `SFTON`・`MSHIFT`・`MFRAME`・`IMOV`・`SMOVL/J/C/S` がある（原本より厳しい追加：`SFTOF` も止める）
- 位置がどの命令にも使われていない
- 位置を2つ以上の命令が使っている（共用。行番号を示す）
- 位置を使う命令が「`MOVL 位置 V=数値`」だけの形でない（MOVL以外、同時移動、PL付き、CR付き、知らない語が付いている）
- PL は値にかかわらず止める（`PL=0` も止める。下の「食い違い」を参照）
- 丸めると値が変わらない
- （仕様v2.1 6章）この位置から出る移動命令（次の移動命令）が「`MOVL 位置 V=数値`」の形でない（MOVJ・MOVC・PL付き・CR付き・同時移動・知らない語）。次の移動命令が無いときは止めない

### 速度の変更（`plan_speed`）を断るもの
- 上の「ジョブ全体を止める」ものがある
- MOVL でない、速度が数値で書かれていない、PL・CR が付いている（`PL=0` を含む）、知らない語が付いている
- 新しい速度が bool、数値でない、正の有限数でない
- 丸めると値が変わらない、または 0 になる
- （仕様v2.1 6章）直前・直後の移動命令に PL・CR が付いている（PL=0 も今は止める）。前後に移動命令が無いときは止めない

### 変更案に入れる注意
- 前後の経路が変わること（`PATH_WARNING`）
- ツール番号・ユーザ座標
- 丸めた場合の実際の変化量
- ジョブに `JUMP`・`CALL`・`RET` がある場合、前後の移動は行の並びからの推定であること
- 速度の単位が設定で変わり得ること（`SPEED_UNIT_WARNING`）

### PL=0 の扱いの食い違い（確認待ち）
- CLAUDE.md：「PL>0 を止める」（PL=0 は止める対象として書かれていない）
- PR #1 修正の原本テスト：`test_pl0_is_allowed`（PL=0 は許す）
- チャッピーの暫定判断：**PL=0 も拒否**（現在の実装とテスト `test_pl0_is_rejected` はこちら）
- 正本（仕様v2.1 6・7章、CURRENT_DECISIONS 4章）は **PL=0 を通す前提**（「PL=0 で作る・PL>0 を止める」）。現在の実装はこれより厳しい

本人の確認で決まるまでは、厳しい方（PL=0 も止める）に合わせる。

**検査を通ったことは、物理的な安全の保証ではない。** 変更後の経路は、人が確かめてから承認する。
