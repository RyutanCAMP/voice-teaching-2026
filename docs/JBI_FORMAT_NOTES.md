# JBIの書き方：前提と確認待ちの点

`samples/dummy/` のジョブは、このリポジトリで新しく作った**架空のジョブ**です（実機のジョブではありません）。
安川のJBIの一般的な書き方をもとにしています。次の点は、実機で作ったサンプルで確認してから確定します。

| 前提 | 状態 |
|---|---|
| 位置は `//POS` の中に `C00000=X,Y,Z,Rx,Ry,Rz` の形で並ぶ | 確認待ち |
| `///POSTYPE ROBOT` と `///RECTAN` のとき、位置はロボット座標（mm・度） | 確認待ち |
| 命令は `//INST` の下に1行ずつ並び、`MOVL C00003 V=80.0` の形で書かれる | 確認待ち |
| 直線速度 `V=` の単位 | 確認待ち（表示単位の設定で変わる可能性） |
| `PL=` が付くと角を内回りする（このアプリでは止める） | 確認待ち |
| 改行コード、文字コード | 読み込んだファイルのものをそのまま保つ |

## このアプリの方針
- 分からない行は、**一文字も変えずにそのまま残す**
- 変えるのは、検査を通った位置の数値1つ、または速度の数値1つだけ
- 位置の形式がロボット座標でないジョブ、PL付きの命令、MOVL以外の移動命令は、変更しない（止める）
