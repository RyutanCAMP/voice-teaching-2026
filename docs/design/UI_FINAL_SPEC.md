## 1. 基本方針
**「一目でわかる。直感的に使える。誰でも迷わない。」**

- 高級感のあるダークテーマ・近未来的で洗練されたデザイン（今のダークテーマのまま）
- 余計な文字や説明を減らす。詳しい説明は「？」の中へ
- 操作すべき場所が一目でわかる（目立たせるボタンは1つ）
- 3D シミュレーションを大きく
- 安全上の重要な情報は省略しない
- 派手なのは起動のとき（オープニング）だけ。ふだんの操作は静かでシンプル

## 2. レイアウト（確定）
| 左：音声入力・会話 | 右：3D シミュレーション |
|---|---|
| 初期は大きなマイクが主役。会話が始まったら会話の履歴が主役、マイクは小さく入力欄の横へ。文字でも入力できる | JOB の動きを3Dで。対象の位置・変更範囲・変更前後を比べる。操作中もいつも見える |

## 3. 画面の流れ（確定）
初期は音声が主役 → 会話が始まったら履歴が主役 → 変更のときは3Dと確認が主役。

| STEP | 画面 | 決まり |
|---|---|---|
| 1 初期 | 左に大きなマイク、右に3D。見出し「ロボットの動きについて話しかけてください」 | 余計な説明は出さない |
| 2 音声入力 | マイクを押して話す → 聞き取った文が入力欄に入る | **聞き取っただけでは送らない**。人が確かめて［送る］ |
| 3 会話 | 最初の送信で、左が会話の履歴の画面になる。マイクは小さく | 右の3Dは出したまま |
| 4 変更候補 | 対象の位置・範囲、変更前後、3D の変更後（オレンジ）。止まった候補は赤い帯と、3D の灰色の点線と ✕ | 安全上の拒否・警告ははっきり出す |
| 5 承認 | 確認表示のボタンで承認 | 承認の段ではマイクを出さない。実機への転送・起動はしない |

## 4. 個別ヘルプ（「？」）
- 長い説明を出しっぱなしにしない。各項目の横の小さな「？」で、必要なときだけ短い説明と例を出す
- 開く：マウスを合わせる・押す（タップ）・キーボード（Tab で合わせる）。閉じる：マウスを外す・もう一度押す・×・Esc・外を押す
- 置いた所と中身（`highlight.js` の `TIPS`）：マイク／移動量（例：Zプラス方向に10mm）／回数（例：3回にして）／変更範囲（どの位置からどの位置まで変更するか確認します）／位置を選ぶ／上下の向き／3D の再生／承認／アプリの記録
- できない操作を、できるように書かない（回数は 2回→3回 だけ、など）

## 5. 間違った入力の案内（「次にすること」）
- サーバーの返事（今の検査の結果・決まった文）に合わせて、理由の下に「次にすること」を1行添える（`highlight.js` の `NEXT_STEPS`）
- 理由の文はそのまま出す（安全の拒否理由を隠さない）。案内だけで安全のエラーを解消したことにしない
- 例は決まった文だけ。押しても入力欄に入れない（人の言葉から正しい指示を推測して入れない）
- 入力の読み方・安全の判定は変えない（サーバーは変えていない）

| サーバーの文（頭） | 次にすること |
|---|---|
| どの方向… | 移動する方向を指定してください。例：「Zプラス方向に10mm」 |
| 何mm動かしますか／量がはっきりしません | 移動量を、数と mm で指定してください。例：「Zプラス方向に10mm」 |
| 位置が決まっていないため… | 先に、右の図の点か下の番号で位置を選んでください |
| 回数は整数で言ってください | 回数を、整数で指定してください。例：「3回にして」 |
| 区間（…）の中に、区間の外の位置… | 指定された範囲では変更できません。対象の位置を確認してください（範囲の例は出さない） |
| 位置 C… はこのジョブにありません | 対象の位置を確認してください |

- 足さないもの：すでに例を含む文・できない操作（前・後ろ、DOUT を含む区間など）・上限を超えた量・2択で聞き返す文
- 回数が分からない文（「回数を変えて」）は、会話の定型文が「何回にするかを、数で言ってください（例：3回にして）」と言う（今のまま）

## 6. オープニング
- 画面を開いたとき（起動）だけ。約3.3秒：暗い画面と走る光 → ロゴ VOICE TEACHING → ROBOT・TOOL・JOB が順に点灯 → READY → メインの画面へ
- 飛ばす：画面を押す・［SKIP］・Esc・Enter・Space。もう一度見る：右下の［▶ オープニング］（撮影用）。`?opening=1` で必ず出す・`?opening=0` で出さない
- 動きを減らす設定：止めた絵を約1.4秒だけ（動かさない・光らせない）
- 音：自動で出すときは無音（ブラウザーの決まり）。［▶ オープニング］で出したときだけ、短い電子音（ピピッ・カチカチ・シュン）
- 確かめていない接続・安全を言わない：

| 行 | 表示 |
|---|---|
| ROBOT | SIMULATION ONLY（実機に接続しません） |
| TOOL | NOT CHECKED（確認していません） |
| JOB | 読み込む前は NOT LOADED。読み込んだあとは LOADED とファイル名（読み込んだことだけ） |
| READY | シミュレーションの操作を始められます（実機の接続・安全の確認ではありません） |

- 文字の大きさ（11/5 夜の唐川さんの指示：離れて見ても読める。色・光・テンポは変えない）。画面の幅に合わせて変わる：

| 文字 | 1280×720 | 1920×1080 |
|---|---|---|
| VOICE TEACHING | 79px | 100px |
| ROBOT・TOOL・JOB と値 | 20px | 26px |
| 補足（実機に接続しません など） | 15px | 19px |
| READY | 59px | 70px |
| READY の補足 | 17px | 21px |

- 1280×720・1366×768・1920×1080 で、文字が画面の外に出ない・切れない・折り返さないことを確かめた
- 下の画面の読み込みは止めない。自動の試験（`navigator.webdriver`）では自動で出さない
- ブラウザーには何も覚えさせない（会話の意味を保存しない決まり E2-6 と同じく、sessionStorage も使わない）

## 7. 変えないもの

- P1-C の修正（範囲を言った回数の指示を、プログラムの区間に広げない）
- 実機への転送・起動は無い。モックと本物の Claude の区別（話し手の表示）
