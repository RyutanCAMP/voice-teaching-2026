# 実機確認の手順（HC20 / YRC1000）

この手順は、会社のPCで実機のジョブを確かめるときに使います。
**今の段階では、アプリはジョブを書き出しません。** 実機の確認は「読む・見る」だけです。
アプリの検査を通ったことは、物理的な安全の保証ではありません。動かすかどうかは人が決めます。

## 今夜（11/2）できること・できないこと
| できる | できない（作っていない、またはレビュー前） |
|---|---|
| 実機のジョブを読み、形式・位置・命令を一覧と2Dの図で見る | ジョブの書き出し・USBへの出力・転送 |
| 位置ごとに、このアプリの検査で変えられるかと、その理由を見る | 音声入力、Claudeによる解釈、承認画面 |
| 分からない書き方（`problems`）がどれだけあるかを知る | 3D表示、シミュレーションの再生 |

## 1. 準備（会社のPC）
1. `git fetch` → `git checkout fix/safety-guards` → `git pull`
2. `python -m pytest -q` を実行し、すべて通ることを確かめる（通らなければ、ここで止めてクロに連絡）
3. 実機のジョブを置くフォルダを、**リポジトリの外**に作る（例：`C:\vt_private\`）。
   実機のジョブは、どのリポジトリにも入れない。Claude にも送らない

## 2. ジョブを読む（読むだけ）
1. ペンダントからUSBでジョブ（.JBI）を保存し、PCの上のフォルダへ写す
2. 次のコマンドを実行する（ジョブは書き換えない。HTML だけを作る）
   ```
   python -m voice_teaching.inspect_job C:\vt_private\ジョブ名.JBI --out C:\vt_private\out
   ```
3. 出てきた HTML を Chrome で開く。HTML も実機のデータなので、リポジトリの外に置く

## 3. 人が確かめること（チェック表）
クロに伝えるのは「形式」と「書き方」だけにする（実機の数値・コメント・ジョブの中身はそのまま送らない）。

| # | 確かめること | 見る場所 | 結果 |
|---|---|---|---|
| 1 | 位置の保存形式（`///POSTYPE` が ROBOT か PULSE か。`///RECTAN` があるか）**最重要** | 一覧の「形式」 | |
| 2 | 表示された C00001 などの値が、ペンダントの位置表示（ロボット座標）と合っているか（2〜3点） | 一覧の「ファイルの行」とペンダント | |
| 3 | ツール番号（`///TOOL`）、`///RCONF`（形態）、`///USER` の書き方 | 一覧の「形式」 | |
| 4 | MOVL に `PL=` が書かれているか。PL=0 が `PL=0` と書かれるのか、何も書かれないのか | 移動命令の一覧 | |
| 5 | `CR=`、MOVJ・MOVC など MOVL 以外の命令の有無 | 移動命令の一覧 | |
| 6 | `V=` の単位（ペンダントの表示単位の設定） | ペンダント | |
| 7 | 「確認できない点」に出た行（例：`///LVARS`、`//ALIAS`、全角空白入りのコメント） | 「確認できない点」 | |
| 8 | 文字コードと改行（Shift_JIS か、CRLF か） | 一覧の先頭 | |
| 9 | 図の上下左右の向きが、実機の向きと合っているか（「右」がX・Yのどちらで＋か−か） | 図とロボット | |
| 10 | 同じ位置を2つ以上の命令が使っていないか（「共用」と出ていないか） | 一覧の「使っている行」 | |

## 4. 将来、アプリで直したジョブを実機で動かす前に（今夜は対象外）
書き出しが作られ、QA・Safety のレビューと唐川さんの承認を通ってから行う。仕様 v2.1 の6章「撮影前の確認手順」に沿って、次を人が確かめる。
1. 生成したジョブの差分：変わったのは承認した1行だけか（位置の値、または速度の値）。ジョブ名が新しい名前になっているか。元のジョブが残っているか
2. 座標系：変えた位置がロボット座標で、ツール番号・姿勢（Rx・Ry・Rz）・形態（RCONF）が変わっていないか
3. 速度：変えた `V=` の値と単位
4. 動作範囲：動かした点に出入りする区間も横にずれる。動かす向きの空き、周りの物の配置
5. 最初は、カメラの外で低速・ステップで確認する
6. 動作範囲に人がいない（協働ロボットでも）。非常停止の位置を確認する
7. ジョブはペンダントで人が選び、スタートボタンで動かす（アプリからは起動しない）
