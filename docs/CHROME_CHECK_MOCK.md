## 見てほしいこと（UI の信念：一目でわかる。直感的に使える。誰でも迷わない）

## シクロの下見で気づいたこと（直していない。唐川さんの確認のあとで決める）
1. 通常の画面に「このセッション：入力 0・出力 0 トークン…推定 $…」が出る（決まり：トークン・料金は詳細表示へ）
2. 1280×720 では右側が長く、状態の1行や新しい答えが上へ流れて見えなくなる（スクロールが要る）
3. 答えの吹き出しの中に、根拠の命令の行（21行目 MOVL C00001 V=150.0 …）が並ぶ（技術的に見える）
4. 回数の変更の途中でも、入力欄の上に「位置は未選択　選ぶ」が出る（位置を選ぶ話と混ざる）
5. 「3回にして」のあとに「Claude が読んだ変更の希望：回数の変更。記録して表示しただけで…」の吹き出しが、定型文と重なって出る
6. 承認のあとはマイクが無い（文字だけ）。決まりどおりだが、声で質問したいときに迷うかもしれない
